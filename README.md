Proxy Checker v4.1

Массовая проверка HTTP / HTTPS / SOCKS4 / SOCKS5 прокси: доступность, задержка, честный HTTPS, анонимность, страна и оценка качества 0–100.

Python 3.8+ и Tkinter, только стандартная библиотека — ничего устанавливать не нужно.

Что это
Proxy Checker — десктоп-утилита для проверки больших списков прокси. Загрузите список (вставкой или drag&drop), и программа в многопоточном режиме проверит каждый адрес: жив ли прокси, поддерживает ли HTTPS, какова задержка, уровень анонимности, страна и итоговый балл качества. Рабочие прокси можно отфильтровать и сохранить. Язык интерфейса, сервисы проверки и параметры прогона настраиваются и запоминаются между запусками.



Возможности
Проверка

- Протоколы: HTTP, HTTPS, SOCKS4, SOCKS5
- IPv6: адреса вида [2001:db8::1]:8080
- Авторизация: форматы host:port:user:pass и URL-схемы с логином/паролем
- Честный HTTPS: настоящий CONNECT-туннель с TLS-рукопожатием через прокси, а не просто «порт 443 открыт»
- Анонимность: elite / anonymous / transparent — по заголовкам, которые прокси добавляет к запросу (Via, X-Forwarded-For и др.)
- Гео: страна и двухбуквенный код (RU, DE, US…)
- Целевые URL: можно указать несколько своих адресов; для каждого живого прокси проверяется доступность и код ответа
- Скоринг 0–100: сводная оценка качества каждого прокси
- Ротация User-Agent: случайный реалистичный UA на каждый запрос


Скорость и надёжность

- Многопоточная проверка; число потоков и таймауты настраиваются и сохраняются в настройках
- Одно TCP-соединение на эндпоинт — проверка SOCKS не открывает лишних коннектов
- Резервные alive-эндпоинты: gstatic → google → cloudflare; недоступность одного сервиса не ломает проверку
- Умный ретрай: повторяются только таймауты и «нет ответа»; однозначные отказы не тратят попытки
- DNS-кэш с TTL 300 с: повторные проверки не создают лишних DNS-запросов, кэш корректно устаревает
- Пауза/продолжение в любой момент
- Стабильная сортировка: строки таблицы не перескакивают, пока идёт проверка


Интерфейс

- Двуязычный интерфейс RU / EN
- Таблица результатов: прокси, протокол, статус, задержка, HTTPS, анонимность, страна, скоринг — с сортировкой по любой колонке
- Фильтр с автодополнением
- Живая статистика: всего / проверено / живых / мёртвых, прогресс прогона
- Автосохранение результатов в процессе + ручной экспорт в файл


Настройки и сервисы

Диалог «Сервисы…»: свои alive-эндпоинты, эхо-URL (для анонимности) и гео-сервис; всё заменяемое
Запоминание настроек: язык, сервисы, целевые URL, потоки и таймауты восстанавливаются при запуске
Защита от гонки: кнопка «Сервисы…» блокируется на время проверки — нельзя подменить эндпоинты посреди прогона


Как работает проверка

1. Парсинг списка. Поддерживаемые форматы:


- 127.0.0.1:8080

- 127.0.0.1:8080:login:pass

- socks5://127.0.0.1:1080

- [2001:db8::1:8080



2. Проверка доступности (alive). Для каждого прокси открывается ровно одно TCP-соединение и отправляется запрос к первому доступному сервису из цепочки alive-URL. Для SOCKS рукопожатие и запрос идут по этому же соединению — никакого двойного коннекта, лишней задержки и расхождения вердиктов.

3. Полная проверка. У живых прокси измеряется задержка, выполняется честный HTTPS-тест (CONNECT + TLS), запрос к эхо-серверу для классификации анонимности, запрос к гео-сервису и проверка целевых URL (доступность + HTTP-код ответа). Ретрай выполняется только для «мягких» отказов — таймаут и отсутствие ответа. «Жёсткие» отказы (соединение отклонено, ошибка авторизации) считаются окончательными.

4. Скоринг и вывод. Итоговая оценка 0–100 учитывает результаты проверки — задержку, HTTPS, анонимность и доступность целевых URL. Чем выше балл, тем надёжнее прокси. Результат добавляется в таблицу; фильтры и сортировка работают поверх без перескакивания строк.



DNS-кэш (TTL 300 с). Резолвинг хоста выполняется один раз и кэшируется на 5 минут: прогон большого списка не перегружает DNS и идёт быстрее. Записи устаревают по TTL, поэтому смена DNS-записи подхватывается при следующей проверке.



Гео-определение

По умолчанию используется ip-api.com — бесплатный сервис с лимитом 45 запросов в минуту. Возвращает название страны и двухбуквенный ISO-код. Сервис можно заменить своим в диалоге «Сервисы…».



Настройки

Файл настроек: %APPDATA%\ProxyChecker\settings.json (создаётся автоматически).



Сохраняется: язык интерфейса, настраиваемые сервисы (alive, эхо, гео), целевые URL, число потоков, таймауты.



Структура — иллюстративная:


    "language": "ru",

    "threads": 100,

    "timeout": 10,

    "services": {

    "alive": ["http://www.gstatic.com/generate_204", "..."],

    "echo": "...",

    "geo": "http://ip-api.com/json/"

    "targets": ["https://example.com"]


Преимущества

Ноль зависимостей. Скачал — запустил: весь функционал на stdlib, ничего устанавливать не нужно.
Точные результаты. Одно соединение на эндпоинт, честный HTTPS-тест через CONNECT, ретраи только там, где это осмысленно.
Устойчивость прогона. Цепочка резервных alive-сервисов и DNS-кэш с TTL — сбой внешнего сервиса или DNS не ломает проверку.
Контроль. Свои сервисы проверки, свои целевые URL, настраиваемые потоки и таймауты — всё через интерфейс и с сохранением.
Комфорт. RU/EN, пауза, drag&drop, фильтр с автодополнением, статистика, стабильная таблица.
Прозрачность. Приложение обращается только к настроенным сервисам проверки и через сами прокси; телеметрии нет.
